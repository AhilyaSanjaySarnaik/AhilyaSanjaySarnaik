## 🔬 Featured Research

### 🔐 Federated Learning for Network Intrusion Detection

Research project exploring **privacy-preserving Network Intrusion Detection Systems (NIDS)** using Federated Learning.

The research investigates distributed anomaly detection where models learn from different network environments without requiring raw traffic to be centrally collected.

**Research focus**

* Federated Learning
* Network Intrusion Detection
* Autoencoder-based Anomaly Detection
* Non-IID / Statistical Heterogeneity
* Adaptive Model Aggregation
* Privacy-Preserving Security

**Datasets**

`NSL-KDD` • `UNSW-NB15`

**Federated Learning Strategies**

`FedAvg` • `FedProx` • `FedAdam` • `Adaptive Aggregation` • `PerFedHypID`
