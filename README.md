### What I work on

I build tools at the intersection of machine learning and security operations —
turning noisy cloud audit logs, recon data, and threat signals into something an
analyst can act on.

- **Cloud telemetry & anomaly detection** — parsing CloudTrail-style logs and
  applying ML to surface point anomalies and volumetric spikes.
- **VAPT automation** — cutting manual busywork out of recon, asset discovery,
  and vulnerability triage.
- **Threat modeling** — data-driven approaches to advanced malware behavior
  (fileless threats, registry mutations, C2 beaconing).

- **[Cloud-Telemetry-Anomaly-Detector](https://github.com/ahilyasanjaysarnaik/Cloud-Telemetry-Anomaly-Detector)**
  — A two-layer detector for CloudTrail-style logs: an Isolation Forest for
  point anomalies plus a robust rate rule for volumetric spikes the ML layer
