## 🔬 Featured Research

### Federated Learning for Network Intrusion Detection

My current security research explores **privacy-preserving Network Intrusion Detection Systems using Federated Learning**.

The research investigates how distributed anomaly detection can be performed across multiple clients without centrally collecting raw network traffic.

**Research focus:**

* 🌐 Federated Learning for NIDS
* 🧠 Autoencoder-based Anomaly Detection
* 🔒 Privacy-Preserving Security Analytics
* 📉 Statistical Heterogeneity & Client Drift
* ⚙️ Adaptive Federated Aggregation
* 📊 Network Threat Detection
* 🧪 Experimental Evaluation of FL Strategies

**Datasets:**

* NSL-KDD
* UNSW-NB15

**Federated Learning strategies investigated:**

* FedAvg
* FedProx
* FedAdam
* Adaptive Aggregation
* PerFedHypID

### Adaptive Aggregation Research

A key part of the research is a **cosine-similarity gated adaptive aggregation strategy** designed to reduce the effect of client updates that diverge significantly from the current global model under non-IID network traffic distributions.

The approach evaluates the geometric alignment between client updates and the global model before determining their contribution to aggregation.
